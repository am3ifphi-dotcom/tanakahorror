# 主人公のSVG原稿

- 出発点はリポジトリ既存の `girl_idle.png`（60×60px）のみです。元ファイルは変更していません。
- `girl-front.svg`：元画像のピクセルを保持し、髪に残っていた白・灰色のマットと足元の焼き込み影を除去。セリフ欄もこのSVGを直接読み込みます。靴下の外側に残っていた47～50行目の灰色も除去しています。
- `girl-right.svg`：元画像から採取した髪・服のピクセルと配色を使用。頭を丸く保ち、元画像の目のピクセルを一つ使用。鼻の突出を1ピクセルに抑え、以前の濃い口・顎の線を撤去。片側の袖と小さな右向きの靴を60×60pxの格子上で再構成した右横向き。
- `girl-left.svg`：右横向きの左右反転。元資料に左右非対称の設定はないため、追加の設定は設けていません。
- `girl-back.svg`：元画像の髪を使った背面の補完。元画像から見えない部分の正解を断定するものではありません。
- `girl-walk.svg`：ゲームが実際に読み込む4方向×4コマのSVG。脚を前後逆に動かし、横向きでもつま先の向きを維持しています。
- 各SVGは `shape-rendering="crispEdges"` を使用したピクセル単位の矩形です。ぼかし・アンチエイリアス・白い縁取りは使用していません。
- 同名PNG類は等価なラスター版です。
- 再生成：`python scripts/prepare-character.py`（Pillowが必要）。

途中で作成した別のAI生成横向き画像は**不採用**です。このSVGおよびゲーム内画像の生成には使っていません。

元画像の原作者・利用許諾範囲は未確認です。SVG化によって新たに自由な利用許諾が付与されるものではありません。

## 横向きの髪の整合（更新5）

正面・背面のピクセルは変更せず、横向きの髪だけを修正しました。

- 頬の脇の毛束：肩までだったものを、前後の絵と同じ裾付近（y=43）まで延長。
- 後ろの髪：横向きだけ下がっていた毛先（y=47）を y=43 に揃え、厚みを縮小。
- 髪の面：元絵の一部を横に引き伸ばしていた処理を廃止。元絵の茶色の配色で、縦に落ちる大きな明暗の面に整理。細い毛筋や装飾は追加していません。
- 頭頂から毛束へのつなぎ目を馴染ませ、横方向の帯状ノイズを抑制。
- 顔の目・頬、靴のピクセルは前の修正版から維持。
- 左向きと全歩行コマも同時に更新。白縁・足横の残留背景に対する回帰検査を実施。

## ファイル構成（重複なし・16コマ）

| ファイル | 中身 |
|---|---|
| `girl-{front,left,right,back}.png` / `.svg` | 立ち絵＝**歩行コマ0**（セリフ欄の立ち絵もこれ） |
| `girl-{front,left,right,back}-walk-{1,2,3}.png` / `.svg` | 歩行コマ1〜3 |
| `girl-walk.svg` | ゲームが読み込む4方向×4コマのシート（240×240） |

- コマ0は立ち絵そのものなので、`-walk-0` というファイルは置いていません（同一画像のコピーを作らない方針）。16枚すべてが異なる絵で、`tests/character.test.js` が重複を検査します。
- `girl-front.svg`：元画像のピクセルを保持し、髪に残っていた白・灰色のマットと足元の焼き込み影を除去。靴下の外側に残っていた47〜50行目の灰色と、両脚の間に閉じ込められていた白背景も除去しています。
- `girl-left.svg` / `girl-right.svg`：支給された左右向きの絵を**そのままの格子で**清書したもの。横顔・姿勢・髪型・服はすべて元絵のピクセルで、描き足した部分はありません（詳細は下記）。
- `girl-back.svg`：元画像の髪を使った背面の補完。元画像から見えない部分の正解を断定するものではありません。
- 各SVGは `shape-rendering="crispEdges"` を使用したピクセル単位の矩形です。ぼかし・アンチエイリアス・白い縁取りは使用していません。PNGは等価なラスター版です。
- 再生成：`python scripts/prepare-character.py`（Pillow と NumPy が必要）。検査：`python scripts/test-character.py`、`npm test`。

元画像の原作者・利用許諾範囲は未確認です。SVG化によって新たに自由な利用許諾が付与されるものではありません。

## 正面も懐中電灯を持ち上げ、歩きの沈み込みを修正（更新9）

横向きは支給絵の通り腕を伸ばして灯りを前に持っているのに、正面だけ両手を体側に下ろしたままだったため、ゲームの灯りの演出（`src/renderer.js` の手元の光点）と噛み合わず、歩きも上下が逆で違和感が出ていました。

### 1. 正面の持ち方（真正面からの短縮描画）

正面からは横向きと同じ「腕を伸ばして持つ」姿は前後に潰れて見えるため、両手を胸元で揃え、ランプを真正面から見た形（暗い外枠＋点灯したレンズ）として描き足しました。

- ランプはゲームの光点（`renderer.js` の `#f5dfad`）と**同色のレンズ**で、描画とエフェクトが一つの灯りに見えるように。
- 手は肌色2pxずつ、袖はドレスの影色で外側へ。選ぶ位置は左右向きの「肩から腕を前に出す」線の延長になる高さ（胸の直下）。
- 背面は変わらずシルエットのまま（後ろからはランプは体に隠れる）。

### 2. 正面・背面の歩行の上下を左右向きに揃える

旧コマ1・3は体が1px**沈んでいました**が、左右向きは1px**持ち上がって**おり、正面だけ歩きが潰れて見えていました。正面・背面も左右向きと同じ「中割りで体を1px持ち上げ」に統一しました。

- 準備として正面・背面のマスターをシート上で1px下げて配置（`FRONT_DROP`、左右の `SIDE_DROP` と同じ発想）。髪の上端が余白を持つので、持ち上げても描画が欠けません。
- 中割りでは振り出す側の脚を1px浮かせて中心線へ1px寄せ、脚の上に空いた行にはドレスの影色を脚の幅の分だけ敷いて、スカートと脚の間の隙間を防ぎます（明るい裾の行をコピーすると明るい帯がはみ出すため、影色で補う）。軸足は動かないので接地線は全コマで同じです。
- 検査：`scripts/test-character.py` の足元の行範囲を新ジオメトリ（脚は48行目以降）に更新。

### 3. ゲーム側の光点位置を実測に合わせる

`TORCH_HAND` を「各スプライトで手（ランプ）がどこにあるか」の実測値（50×50描画に合わせたオフセット）に更新しました。正面は胸のランプ (0,−22)、左は (−12,−15)、右は (12,−14)。灯りの中心が絵の手元からずれていた問題がなくなります。

## 脚の間の白抜き（更新7）

正面・背面の立ち絵と歩行コマで、両脚の間が白い塊で埋まっていました。これは元絵の白い撮影背景が、裾・左右の脚・接した靴に囲まれて「閉じた穴」になっていたためで、外側から流し込むマット除去が届いていませんでした（脚が水かきでつながったように見えていました）。

- 脚の始まる行（47行目）から、マット除去と同じ判定（明るく彩度の低いピクセル）で内側へ流し込み、背景のピクセルだけを透明化。
- 白い靴下は脚の輪郭線で囲まれているため流し込みが届かず、そのまま残ります。
- 靴が触れ合う下端（53行目以降）は元絵でも暗い靴の色なので、そのまま靴として残しています。
- 正面から作る背面と、正面・背面の歩行コマにも同じ修正が反映されます。
- 検査：`scripts/test-character.py` と `tests/character.test.js` が、正面・背面とその歩行コマに「脚の間の透明な隙間」が存在することを確認します。


## 左右向きの清書（更新6）

`girl_left.png` / `girl_right.png` は白背景を抜いた切り抜きで、次の残骸が含まれていました。

1. 足元の灰色の楕円（焼き込みの床影、RGB≈176）
2. 輪郭全体の白～灰色の縁（白背景と混ざったアンチエイリアス）
3. 髪の毛束の隙間に残った白い窓（頭の後ろ・毛先）
4. 毛先の1ピクセル幅のささくれ（髪と背景が1px間隔で交互に並んだ部分）

処理はすべて元の60×60格子上で行い、順に、

- **背景の除去**：彩度が低く明るいピクセル（灰・白）のうち、画像の外側とつながるものを床影・縁ごと透明化。
- **輪郭の復元**：残った縁のピクセルは「元絵の色 × 被覆率 + 白 × (1−被覆率)」とみなし、被覆率を推定。半分未満なら削除、半分以上なら白を差し引いた色に戻す（足元では白ではなく床影の灰色を差し引く）。これで暗い画面に乗せても灰色のハローが出ません。
- **毛束の窓**：髪に完全に囲まれた白い窓は、周囲の髪色で塗る。頭の後ろで輪だけが残ったカールは削除し、その窓も髪色に。
- **毛先**：ささくれた毛先は列ごとに下端を1本の線に揃え、孤立した1ピクセルと小さな島を除去。
- 左向きの前髪束の割れ目から覗いていた服の明るい3ピクセルは、ゲーム倍率で白い点に見えるため毛束の色に揃えました。

2枚とも頭頂が画像の上端に接しているため、シート上では全体を1px下げて配置しています（歩行コマで体を1px持ち上げても欠けないため）。

### 歩行コマ（左右）

元絵は「手前の足が前」の接地姿勢です。コマ2では手前の足を後ろへ、奥の足を前へ送って反対側の接地姿勢を作り、コマ1・3はその中間で、振り出している足を1px浮かせ、体を1px持ち上げています。足は常に同じ地面線に接し、裾の2行を脚の下にも敷いて体を持ち上げた際の隙間を防いでいます。

### 懐中電灯

ゲーム側（`src/renderer.js`）では、灯りの光点と手元のにじみを向きごとの手の位置（`TORCH_HAND`）に描くようにしました。左向きのときは左手側、右向きは右手側、正面は手元、後ろ向きは体の向こう側なので光点を描かず髪と肩に淡い照り返しだけを乗せます。床に落ちる光だまりも向いている方向へ滑らかに移動・伸長します（向きを変えると追従、`reduced-motion` 設定では即時）。
